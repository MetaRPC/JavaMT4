# MT4Sugar — Order Management

> Modify SL/TP and close positions — by pips or price, one order or in bulk.

Modify/close rejections throw `ModifyRejected`. Each action emits a hook (`on_modify`, `on_close`, `on_close_by`).

---

## `modifySlTpByPips(int ticket, Double slPips, Double tpPips)`

```java
public void modifySlTpByPips(int ticket, Double slPips, Double tpPips)
```

Set SL/TP as pip distances from the order's **open price** (sign handled by side). Pass `null` to leave one side unchanged.

```java
sugar.modifySlTpByPips(ticket, 40.0, 120.0);   // SL 40 pips, TP 120 pips from entry
```

## `modifySlTpByPrice(int ticket, Double slPrice, Double tpPrice)`

```java
public void modifySlTpByPrice(int ticket, Double slPrice, Double tpPrice)
```

Set SL/TP at absolute prices (normalized to the symbol grid). `null` leaves a side unchanged.

```java
MT4Sugar.Quote q = sugar.lastQuote("EURUSD");
sugar.modifySlTpByPrice(ticket, q.bid - sugar.pipsToPrice("EURUSD", 60), q.ask + sugar.pipsToPrice("EURUSD", 140));
```

---

## `close(int ticket)` · `closePartial(int ticket, double lots)`

```java
public void close(int ticket)
public void closePartial(int ticket, double lots)
```

`close` fully closes a market order (or deletes a pending); `closePartial` closes part of the volume, leaving the remainder open (`lots <= 0` is a no-op).

```java
sugar.closePartial(ticket, 0.01);
sugar.close(ticket);
```

## `closeBy(int ticketA, int ticketB)` · `closeByTickets(int ticketA, int ticketB)`

```java
public void closeBy(int ticketA, int ticketB)
public void closeByTickets(int ticketA, int ticketB)
```

Net two opposite tickets on the same symbol (hedge close-by). `closeByTickets` is an alias kept for parity with the Python API; they differ only in the hook payload emitted.

```java
sugar.closeByTickets(buyTicket, sellTicket);
```

---

## `closeAll(String symbol, Integer magic, Boolean onlyProfit)`

```java
public void closeAll(String symbol, Integer magic, Boolean onlyProfit)
```

Close every open order, optionally filtered. `symbol`/`magic` restrict the set (`null` = any); `onlyProfit` = `true` closes only winners, `false` closes only losers, `null` closes all.

```java
sugar.closeAll("EURUSD", null, null);     // flatten everything on EURUSD
sugar.closeAll(null, 777, true);          // take profit on all magic-777 winners
```

## `cancelPendings(String symbol, Integer magic)`

```java
public void cancelPendings(String symbol, Integer magic)
```

Delete pending orders only (market positions untouched), optionally filtered by symbol/magic.

```java
sugar.cancelPendings("EURUSD", null);
```
