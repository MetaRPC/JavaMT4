# MT4Sugar — Watchers & Waiters

> Background stream subscriptions (watchers) and blocking awaiters for order lifecycle.

Each `watch*` wraps the matching [MT4Account stream](../MT4Account/5.%20Streaming_Methods/Streaming_Methods.Overview.md) and returns a `String` subscription id stored internally; stop any of them with `unwatch(id)`. The waiters block (polling) until a condition is met.

---

## Watchers

```java
public String watchTicks(String symbol, Consumer<OnSymbolTickData> onTick, Consumer<Throwable> onError)
public String watchTrades(Consumer<OnTradeData> onEvent, Consumer<Throwable> onError)
public String watchOpenedOrders(Consumer<OnOpenedOrdersTicketsData> onEvent, Consumer<Throwable> onError)
public String watchProfit(Consumer<OnOpenedOrdersProfitData> onEvent, int timerPeriodMs, Consumer<Throwable> onError)
public String watchTickets(Consumer<OnOpenedOrdersTicketsData> onEvent, int pullIntervalMs, Consumer<Throwable> onError)
```

| Method | Streams | Notes |
|--------|---------|-------|
| `watchTicks` | live bid/ask for one symbol | ensures the symbol first |
| `watchTrades` | trade events (new/updated/removed) | |
| `watchOpenedOrders` | open-ticket snapshots | fixed 500 ms sampling |
| `watchProfit` | floating P/L on a timer | `timerPeriodMs` interval |
| `watchTickets` | open-ticket snapshots | `pullIntervalMs` interval |

`onError` may be `null` (errors are then ignored).

```java
String w1 = sugar.watchTicks("EURUSD", d -> { /* d.getSymbolTick()... */ }, null);
String w2 = sugar.watchProfit(d -> { }, 1000, null);
// ... later:
sugar.unwatch(w1);
sugar.unwatch(w2);
```

## `unwatch(String subscriptionId)`

```java
public void unwatch(String subscriptionId)
```

Cancel any worker/subscription created by a `watch*`, `setTrailingStop` or `autoBreakeven` call (closes the underlying `Subscription` / stops the thread).

---

## Waiters

## `waitFilled(int ticket, Long timeoutMs)`

```java
public OpenedOrderInfo waitFilled(int ticket, Long timeoutMs)
```

Block until the order is no longer pending (i.e. filled), returning its `OpenedOrderInfo`. Throws `MT4Error` on timeout (`null` = wait indefinitely).

```java
sugar.waitFilled((int) ticket, 10_000L);
```

## `waitClosed(int ticket, Long timeoutMs)`

```java
public Map<String, Object> waitClosed(int ticket, Long timeoutMs)
```

Block until the order leaves the open list (closed), returning a small map `{ticket, status:"closed", symbol?, lots?}`. Throws `MT4Error` on timeout.

```java
System.out.println(sugar.waitClosed((int) ticket, 10_000L).get("status"));   // "closed"
```
