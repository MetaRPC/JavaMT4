# MT4Sugar — Trailing & Breakeven

> Background workers that manage a stop for you, plus a one-shot move-to-breakeven.

`setTrailingStop` and `autoBreakeven` start a **daemon worker thread** and return a `String` subscription id; stop them with `unsetTrailingStop(id)` or `unwatch(id)`. Each SL move emits an `on_modify` hook.

---

## `setTrailingStop(int ticket, double distancePips, Double stepPips)`

```java
public String setTrailingStop(int ticket, double distancePips, Double stepPips)
```

Start trailing the stop `distancePips` behind the mid price (in the favorable direction only — it never loosens an existing SL). `stepPips` (optional) suppresses tiny adjustments smaller than that step. Returns the worker id. Throws if `distancePips <= 0`.

```java
String id = sugar.setTrailingStop(ticket, 30, 10.0);   // trail 30 pips behind, min 10-pip steps
// ... later:
sugar.unsetTrailingStop(id);
```

## `unsetTrailingStop(String subscriptionId)`

```java
public void unsetTrailingStop(String subscriptionId)
```

Stop a trailing worker (alias of `unwatch`).

---

## `autoBreakeven(int ticket, double triggerPips, double plusPips)`

```java
public String autoBreakeven(int ticket, double triggerPips, double plusPips)
```

Start a worker that, once price moves `triggerPips` in profit, moves the SL to the entry price `± plusPips` (locking in a small gain) and then stops itself. Returns the worker id. Throws if `triggerPips <= 0`.

```java
String id = sugar.autoBreakeven(ticket, 20, 2.0);   // after +20 pips, SL -> entry +2
// stop early if needed:
sugar.unwatch(id);
```

## `closeByBreakeven(int ticket, double plusPips)`

```java
public void closeByBreakeven(int ticket, double plusPips)
```

A **one-shot** move of the SL to the entry price `± plusPips` (not a worker) — makes the trade risk-free immediately.

```java
sugar.closeByBreakeven(ticket, 2.0);   // SL -> entry +2 pips now
```

---

## 🧩 Notes

* **Daemon threads.** Workers are daemon threads polling every ~0.3 s; they exit on their own when the order disappears or the quote read fails.
* **One id per worker.** Keep the returned id to stop the worker; `unwatch` and `unsetTrailingStop` are interchangeable.
* **Direction-aware.** For a BUY the stop trails up / breakeven sits above entry; for a SELL it's mirrored.
