# MT4Sugar — Order Info & Exposure

> Query open orders, aggregate exposure, and a one-call diagnostics snapshot.

These read `openedOrders()` and summarize it; the exposure helpers return the plain-data `ExposureBucket` / `ExposureSummary` holders.

---

## `findOrders(String symbol, Integer magic, String side, String state, Double minProfit)`

```java
public List<OpenedOrderInfo> findOrders(String symbol, Integer magic, String side, String state, Double minProfit)
```

Open orders filtered by any combination (pass `null` to skip a filter):

* `symbol` — exact (case-insensitive),
* `magic` — magic number,
* `side` — `"buy"` / `"sell"`,
* `state` — `"open"` (market only), `"pending"` (pending only), or `null` (all),
* `minProfit` — keep only orders with profit ≥ this.

```java
var buys = sugar.findOrders("EURUSD", null, "buy", "open", null);
System.out.println(buys.size() + " open BUYs on EURUSD");
```

## `ordersForSymbol(String symbol)`

```java
public List<OpenedOrderInfo> ordersForSymbol(String symbol)
```

All open orders (market + pending) for one symbol.

```java
System.out.println(sugar.ordersForSymbol("EURUSD").size());
```

---

## `positionsValue(String symbol, Integer magic)`

```java
public ExposureBucket positionsValue(String symbol, Integer magic)
```

Aggregate **market positions** (pendings excluded) for a symbol into one `ExposureBucket` (`lotsLong`, `lotsShort`, `lotsNet`, `pnl`), optionally filtered by `magic`.

```java
MT4Sugar.ExposureBucket pv = sugar.positionsValue("EURUSD", null);
System.out.printf(Locale.ROOT, "net %.2f lot, pnl %.2f%n", pv.lotsNet, pv.pnl);
```

## `exposureSummary()`

```java
public ExposureSummary exposureSummary()
```

Account totals plus per-symbol and overall exposure across all open orders:

| Field | Meaning |
|-------|---------|
| `balance`, `equity` | from `accountSummary()` |
| `openPositions` | count of open orders |
| `bySymbol` | `{SYMBOL → ExposureBucket}` |
| `total` | overall `ExposureBucket` (net/long/short lots, pnl) |

```java
MT4Sugar.ExposureSummary e = sugar.exposureSummary();
System.out.printf(Locale.ROOT, "equity %.2f | net %.2f lot | pnl %.2f%n",
        e.equity, e.total.lotsNet, e.total.pnl);
```

---

## `diagSnapshot()`

```java
public Map<String, Object> diagSnapshot()
```

A compact diagnostics blob — good for dashboards/logging. Keys: `generated_at_ms`, `account` (`{balance, equity}`), `exposure` (an `ExposureSummary`), `open_orders_count`, and `spreads` (`{SYMBOL → {bid, ask, spread_pips}}` for open-order symbols plus the default symbol).

```java
System.out.println(sugar.diagSnapshot().keySet());
```
