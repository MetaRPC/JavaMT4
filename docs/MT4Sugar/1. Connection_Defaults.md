# MT4Sugar — Connection & Defaults

> Session helpers and shared defaults that the rest of the Sugar API reuses.

---

## `ensureConnected()`

```java
public void ensureConnected()
```

Assert the underlying session has been connected (throws `MT4Error` otherwise). Most Sugar methods call this for you.

```java
sugar.ensureConnected();
```

## `ping()`

```java
public boolean ping()
```

Lightweight liveness check — does an `accountSummary()` and returns `true`/`false`.

```java
System.out.println("alive: " + sugar.ping());
```

## `ensureSymbol(String symbol)`

```java
public void ensureSymbol(String symbol)
```

Make a symbol ready to use — loads and caches its parameters (so later math calls are cheap).

```java
sugar.ensureSymbol("XAUUSD");
```

---

## `setDefaults(String symbol, Integer magic, Double deviationPips, Double slippagePips, Double riskPercent)`

```java
public void setDefaults(String symbol, Integer magic, Double deviationPips, Double slippagePips, Double riskPercent)
```

Set values reused across calls. A `null` argument leaves that default unchanged. Order entry falls back to `symbol`/`magic`/`deviationPips` when you pass `null` there.

```java
sugar.setDefaults("EURUSD", 777, 3.0, null, 1.0);
```

## `getDefault(String key)`

```java
public Object getDefault(String key)
```

Read a current default. Keys: `"symbol"`, `"magic"`, `"deviation_pips"`, `"slippage_pips"`, `"risk_percent"` (returns `null` if unset or unknown).

```java
System.out.println(sugar.getDefault("symbol") + " / " + sugar.getDefault("risk_percent"));
```

---

## `disconnect(boolean delete)`

```java
public void disconnect(boolean delete)
```

Release the session (delegates to the service). Pass `true` to also delete the terminal instance.

```java
sugar.disconnect(false);
```
