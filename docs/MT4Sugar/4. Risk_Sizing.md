# MT4Sugar — Risk Sizing

> Turn a risk budget into a lot size, and value a stop in cash.

These use the symbol's tick value and pip size to convert between pips, lots and money. (`exposureSummary` lives in [9. Order Info & Exposure](./9.%20Order_Info.md).)

---

## `calcLotByRisk(String symbol, double riskPercent, double stopPips, Double balance)`

```java
public double calcLotByRisk(String symbol, double riskPercent, double stopPips, Double balance)
```

The lot size that risks `riskPercent` % of balance over a `stopPips` stop. `balance` is optional — pass `null` to use the live account balance. The result is normalized to the broker's volume step/limits. Throws if `stopPips <= 0`.

```java
double lots = sugar.calcLotByRisk("EURUSD", 1.0, 50, null);   // risk 1% over a 50-pip stop
```

## `calcCashRisk(String symbol, double lots, double stopPips)`

```java
public double calcCashRisk(String symbol, double lots, double stopPips)
```

The cash amount at risk if a `stopPips` stop is hit on `lots` lots.

```java
double risk = sugar.calcCashRisk("EURUSD", 0.10, 50);   // $ at risk
```

## `breakevenPrice(double entryPrice, double commission, double swap)`

```java
public double breakevenPrice(double entryPrice, double commission, double swap)
```

The price at which a position breaks even once costs are included (`entry + commission + swap`, in price terms).

```java
double be = sugar.breakevenPrice(1.10000, 0.0001, 0.0);
```
