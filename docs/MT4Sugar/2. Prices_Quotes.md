# MT4Sugar — Prices & Quotes

> Clean quote/bar/tick reads and a price-wait helper, on top of the raw market calls.

The price helpers return small plain-data holders — `Quote`, `Bar`, `Tick` — instead of protobuf messages.

---

## `lastQuote(String symbol)`

```java
public Quote lastQuote(String symbol)
```

A clean `{bid, ask, time}` snapshot for one symbol. Ensures the symbol is loaded first.

```java
MT4Sugar.Quote q = sugar.lastQuote("EURUSD");
System.out.printf(Locale.ROOT, "%.5f / %.5f%n", q.bid, q.ask);
```

## `midPrice(String symbol)`

```java
public double midPrice(String symbol)
```

The mid price `(bid + ask) / 2`.

```java
double mid = sugar.midPrice("EURUSD");
```

## `spreadPips(String symbol)`

```java
public double spreadPips(String symbol)
```

Current spread expressed in **pips** (`(ask − bid) / pipSize`).

```java
System.out.printf(Locale.ROOT, "spread = %.1f pips%n", sugar.spreadPips("EURUSD"));
```

## `quotes(List<String> symbols)`

```java
public Map<String, Quote> quotes(List<String> symbols)
```

A `{SYMBOL → Quote}` map for several symbols in one round-trip (keys upper-cased).

```java
sugar.quotes(List.of("EURUSD", "GBPUSD"))
     .forEach((k, v) -> System.out.printf(Locale.ROOT, "%s %.5f/%.5f%n", k, v.bid, v.ask));
```

---

## `bars(String symbol, String timeframe, Integer count, Instant since, Instant until)`

```java
public List<Bar> bars(String symbol, String timeframe, Integer count, Instant since, Instant until)
```

Recent OHLC candles as `Bar` objects (`time` epoch-seconds, `open/high/low/close`, `volume` = tick volume). `timeframe` is a string (`"M1".."MN1"`); if `since`/`until` are `null` the service derives a window from `timeframe × count`. The result is trimmed to the last `count` bars.

```java
List<MT4Sugar.Bar> bars = sugar.bars("EURUSD", "H1", 5, null, null);
if (!bars.isEmpty()) System.out.println("last close " + bars.get(bars.size() - 1).close);
```

## `ticks(String symbol, String timeframe, Integer limit)`

```java
public List<Tick> ticks(String symbol, String timeframe, Integer limit)
```

A quick price series derived from candle closes (`bid = ask = close`) — handy for a lightweight series when a true tick stream isn't needed. `timeframe` defaults to `"M1"` when `null`.

```java
System.out.println("points: " + sugar.ticks("EURUSD", "M5", 5).size());
```

---

## `waitPrice(String symbol, double target, String direction, Long timeoutMs)`

```java
public double waitPrice(String symbol, double target, String direction, Long timeoutMs)
```

Block (polling the mid every 250 ms) until the price crosses `target`. `direction` is one of `">="`, `"<="`, `">"`, `"<"`; returns the mid that satisfied it, or throws `MT4Error` on timeout (`timeoutMs = null` waits indefinitely).

```java
double hit = sugar.waitPrice("EURUSD", sugar.midPrice("EURUSD") + 0.0010, ">=", 60_000L);
```
