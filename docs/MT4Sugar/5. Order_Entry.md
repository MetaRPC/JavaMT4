# MT4Sugar — Order Entry

> One-call market and pending entries with **pip-based or absolute** SL/TP, automatic normalization and defaults.

All entries ultimately build an `OrderSendRequest` and call [`MT4Service.orderSend`](../MT4Service/4.%20Trading_Operations.md); they return the new **ticket** (`long`). SL/TP can be given as pip distances (`slPips`/`tpPips`) **or** absolute prices (`slPrice`/`tpPrice`). Lots are normalized to the volume step; a `null` `magic`/`deviationPips` falls back to the defaults from `setDefaults`. Rejections throw `OrderRejected`.

---

## `placeOrder(...)`

```java
public long placeOrder(String side, String orderType, String symbol, Double price, Double lots,
                       Double slPips, Double tpPips, Double slPrice, Double tpPrice,
                       String comment, Integer magic, Double deviationPips)
```

The generic entry the shortcuts delegate to. `side` = `"buy"/"sell"`, `orderType` = `"market"/"limit"/"stop"`. `symbol` may be `null` to use the default symbol; `price` is required for `limit`/`stop`; `lots` defaults to `0.01` when `null`. For market orders the entry price is read live (`ask` for buy, `bid` for sell), and pip-based SL/TP are computed from it.

```java
long t = sugar.placeOrder("buy", "market", "EURUSD", null, 0.01, 50.0, 100.0, null, null, "entry", null, null);
```

## Market shortcuts

```java
public long buyMarket(String symbol, Double lots, Double slPips, Double tpPips, Double slPrice, Double tpPrice, String comment, Integer magic, Double deviationPips)
public long sellMarket(String symbol, Double lots, Double slPips, Double tpPips, Double slPrice, Double tpPrice, String comment, Integer magic, Double deviationPips)
```

Instant BUY/SELL at market.

```java
long t = sugar.buyMarket("EURUSD", 0.01, 50.0, 100.0, null, null, "buy", null, null);
```

## Pending shortcuts

```java
public long buyLimit(String symbol, double price, Double lots, Double slPips, Double tpPips, Double slPrice, Double tpPrice, String comment, Integer magic)
public long sellLimit(String symbol, double price, Double lots, Double slPips, Double tpPips, Double slPrice, Double tpPrice, String comment, Integer magic)
public long buyStop(String symbol,  double price, Double lots, Double slPips, Double tpPips, Double slPrice, Double tpPrice, String comment, Integer magic)
public long sellStop(String symbol, double price, Double lots, Double slPips, Double tpPips, Double slPrice, Double tpPrice, String comment, Integer magic)
```

Resting LIMIT/STOP orders at `price` (normalized to the symbol grid).

```java
double entry = sugar.midPrice("EURUSD") - sugar.pipsToPrice("EURUSD", 100);
long pending = sugar.buyLimit("EURUSD", entry, 0.01, 50.0, 100.0, null, null, "lim", null);
```

---

## 🧩 Notes

* **Pips vs absolute.** Pass `slPips`/`tpPips` for distances from the entry, or `slPrice`/`tpPrice` for exact prices — if both are given, the absolute price wins.
* **Sides.** For a BUY, SL is below entry and TP above; for a SELL it's mirrored — Sugar works this out from `side`.
* **Rate-limited.** Order sends pass through an internal rate limiter to avoid flooding the gateway.
* **Hook.** A successful send emits `on_order_sent` (`{ticket, symbol}`) on `sugar.hooks`.
