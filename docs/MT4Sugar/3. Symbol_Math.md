# MT4Sugar — Symbol Math & Normalization

> Pip/point conversions and broker-grid rounding — the primitives the entry/modify methods build on.

All of these read (and cache) the symbol's parameters from [`symbolParamsMany`](../MT4Account/3.%20Symbols_Quotes/symbol_params_many.md).

---

## `point(String symbol)` · `digits(String symbol)`

```java
public double point(String symbol)
public int digits(String symbol)
```

`point` is the smallest price step (e.g. `0.00001`); `digits` is the number of decimal places. Both fall back to sane values if the broker reports zero.

```java
System.out.printf(Locale.ROOT, "point=%.5f digits=%d%n", sugar.point("EURUSD"), sugar.digits("EURUSD"));
```

## `pipSize(String symbol)`

```java
public double pipSize(String symbol)
```

One pip in price terms — `10 × point` on 3/5-digit symbols, else `point`.

```java
double pip = sugar.pipSize("EURUSD");   // 0.0001 on a 5-digit EURUSD
```

---

## `pipsToPrice(String symbol, double pips)` · `priceToPips(String symbol, double priceDelta)`

```java
public double pipsToPrice(String symbol, double pips)
public double priceToPips(String symbol, double priceDelta)
```

Convert between a pip distance and an absolute price move.

```java
double d = sugar.pipsToPrice("EURUSD", 50);        // 0.0050
double p = sugar.priceToPips("EURUSD", 0.0050);    // 50.0
```

---

## `normalizePrice(String symbol, double price)` · `normalizeLot(String symbol, double lots)`

```java
public double normalizePrice(String symbol, double price)
public double normalizeLot(String symbol, double lots)
```

`normalizePrice` snaps a price to the symbol's point grid; `normalizeLot` snaps a volume to the broker's `VolumeStep` and clamps it into `[VolumeMin, VolumeMax]`.

```java
double price = sugar.normalizePrice("EURUSD", 1.234567);   // -> 1.23457
double lot   = sugar.normalizeLot("EURUSD", 0.037);        // -> 0.04 (step 0.01)
```

---

## `tickValue(String symbol, double lots)`

```java
public double tickValue(String symbol, double lots)
```

Money value of one tick for the given lot size (from [`tickValueWithSize`](../MT4Account/3.%20Symbols_Quotes/tick_value_with_size.md)).

```java
System.out.printf(Locale.ROOT, "tick value = %.5f%n", sugar.tickValue("EURUSD", 0.10));
```
