# MT4Service — Trading Operations

> Order operations with **friendly arguments**, plus one-call **trade shortcuts** that return the ticket.

Two levels here, both on `MT4Service`:

* **Facade pass-throughs** — the same four operations as [MT4Account](../MT4Account/4.%20Trading_Operations/Trading_Operations.Overview.md).
* **Trade shortcuts** — `buyMarket` / `sellLimit` / `close` / … that build the request for you (with `side`/`type` mapping and shared defaults) and return the **ticket** (`long`).

All of these ultimately call [`MT4Account.orderSend`](../MT4Account/4.%20Trading_Operations/order_send.md) & friends, so failures throw `ApiExceptionMT4` — see [Errors](../All_Guides/ERRORS.md).

---

## Facade pass-throughs

```java
public OrderSendData orderSend(OrderSendRequest request)
public OrderSendData orderSend(String symbol, OrderSendOperationType type, double lots)
public OrderModifyData orderModify(int ticket, Double newPrice, Double newStopLoss, Double newTakeProfit, Instant newExpiration)
public OrderCloseDeleteData orderCloseDelete(int ticket, Double lots, Double closingPrice, Integer slippage)
public OrderCloseByData orderCloseBy(int ticketToClose, int oppositeTicketClosingBy)
```

Identical semantics and payloads to the low-level calls — see the MT4Account pages for [order_send](../MT4Account/4.%20Trading_Operations/order_send.md), [order_modify](../MT4Account/4.%20Trading_Operations/order_modify.md), [order_close_delete](../MT4Account/4.%20Trading_Operations/order_close_delete.md), [order_close_by](../MT4Account/4.%20Trading_Operations/order_close_by.md).

## Trade defaults

```java
public void setTradeDefaults(Integer magic, Integer deviationPips, String comment)
```

Stores `magic` / `deviationPips` / `comment` that are mixed into every `buy*`/`sell*` shortcut when that shortcut's own argument is `null`. A `null` here leaves the stored default unchanged.

```java
service.setTradeDefaults(777, 3, "my bot");
```

---

## Market & pending shortcuts

```java
public long buyMarket(String symbol, double lots, Double sl, Double tp, Integer magic, Integer deviationPips, String comment)
public long sellMarket(String symbol, double lots, Double sl, Double tp, Integer magic, Integer deviationPips, String comment)
public long buyLimit(String symbol, double price, double lots, Double sl, Double tp, Integer magic, String comment)
public long sellLimit(String symbol, double price, double lots, Double sl, Double tp, Integer magic, String comment)
public long buyStop(String symbol, double price, double lots, Double sl, Double tp, Integer magic, String comment)
public long sellStop(String symbol, double price, double lots, Double sl, Double tp, Integer magic, String comment)
```

Each opens the corresponding order and returns the **ticket**. `sl`/`tp` are absolute prices (pass `null` for none); market shortcuts also take a per-call `deviationPips`. Pending shortcuts take the entry `price`. Any `null` `magic`/`deviationPips`/`comment` falls back to the stored defaults.

```java
long ticket = service.buyMarket("EURUSD", 0.01, 1.0950, 1.1050, null, null, null);
long pend   = service.buyLimit("EURUSD", 1.0900, 0.01, null, null, null, null);
```

## Manage

```java
public void modifySlTp(int ticket, Double slPrice, Double tpPrice)   // absolute prices
public void close(int ticket)                                        // full close / delete pending
public void closePartial(int ticket, double lots)                    // close part of the volume
public void closeBy(int ticketA, int ticketB)                        // net two opposite tickets
```

```java
service.modifySlTp(ticket, 1.0960, 1.1040);
service.closePartial(ticket, 0.01);
service.close(ticket);
```

> **Even higher level?** [`MT4Sugar`](../MT4Sugar/MT4Sugar.Master.Overview.md) adds pip-based SL/TP, lot sizing by risk, trailing stops and `closeAll`.
