# MT4Service — Streaming Methods

> The same real-time streams as [MT4Account](../MT4Account/5.%20Streaming_Methods/Streaming_Methods.Overview.md), relayed through the facade.

All are callback-based: each returns a `MT4Account.Subscription` (`AutoCloseable`) and delivers to your `Consumer<…Data> onData`; close the subscription to stop. See [Streams](../All_Guides/STREAMS.md).

---

## `onSymbolTick(List<String> symbols, onData, onError)`

```java
public MT4Account.Subscription onSymbolTick(List<String> symbols,
        Consumer<OnSymbolTickData> onData, Consumer<Throwable> onError)
```

Live bid/ask ticks for the given symbols.

```java
try (var s = service.onSymbolTick(List.of("EURUSD", "GBPUSD"), td -> {
        var t = td.getSymbolTick();
        System.out.println(t.getSymbol() + " " + t.getBid() + " " + t.getAsk());
    }, null)) {
    Thread.sleep(5000);
}
```

> **Underlying:** [`MT4Account.onSymbolTick`](../MT4Account/5.%20Streaming_Methods/on_symbol_tick.md).

---

## `onTrade(onData, onError)`

```java
public MT4Account.Subscription onTrade(Consumer<OnTradeData> onData, Consumer<Throwable> onError)
```

Trade events — new / updated / removed orders.

```java
var sub = service.onTrade(ev -> {
    for (var o : ev.getEventData().getNewOrdersList())
        System.out.println("NEW " + o.getTicket() + " " + o.getSymbol());
}, null);
```

> **Underlying:** [`on_trade`](../MT4Account/5.%20Streaming_Methods/on_trade.md) — event structure and `SUB_OP_*` enums.

---

## `onOpenedOrdersTickets(int pullIntervalMilliseconds, onData, onError)`

```java
public MT4Account.Subscription onOpenedOrdersTickets(int pullIntervalMilliseconds,
        Consumer<OnOpenedOrdersTicketsData> onData, Consumer<Throwable> onError)
```

Periodic snapshots of open position / pending ticket lists.

```java
var sub = service.onOpenedOrdersTickets(1000, ev ->
        System.out.println(ev.getPositionTicketsList() + " / " + ev.getPendingOrderTicketsList()), null);
```

> **Underlying:** [`on_opened_orders_tickets`](../MT4Account/5.%20Streaming_Methods/on_opened_orders_tickets.md).

---

## `onOpenedOrdersProfit(int timerPeriodMilliseconds, onData, onError)`

```java
public MT4Account.Subscription onOpenedOrdersProfit(int timerPeriodMilliseconds,
        Consumer<OnOpenedOrdersProfitData> onData, Consumer<Throwable> onError)
```

Live P/L of open orders on a timer.

```java
var sub = service.onOpenedOrdersProfit(1000, ev -> {
    for (var o : ev.getOpenedOrdersWithProfitUpdatedList())
        System.out.println(o.getTicket() + " " + o.getOrderProfit());
}, null);
```

> **Underlying:** [`on_opened_orders_profit`](../MT4Account/5.%20Streaming_Methods/on_opened_orders_profit.md) — `MT4_SUB_ENUM_EVENT_GROUP_TYPE` / `SUB_OP_*` enums.

---

## `onConnectState(List<String> terminalIds, onData, onError)`

```java
public MT4Account.Subscription onConnectState(List<String> terminalIds,
        Consumer<ConnectStateData> onData, Consumer<Throwable> onError)
```

Terminal connection-state changes (connected/alive flags, server, account, timestamp). Pass `null` for the current session.

```java
var sub = service.onConnectState(null, ev ->
        System.out.println(ev.getState() + " " + ev.getIsConnected() + " " + ev.getServer()), null);
```

> **Underlying:** [`on_connect_state`](../MT4Account/5.%20Streaming_Methods/on_connect_state.md).
