# MT4Service — Orders & History

> Open orders and closed history, with **string sort modes** and **`Instant` windows** instead of protobuf enums.

What the facade adds over [MT4Account](../MT4Account/2.%20Orders_History/Orders_History.Overview.md): you pass `sort = "open_desc"` and `since`/`until` instants; the service maps them to the right enum and request fields. The returned payloads are the same typed `…Data` messages.

---

## `openedOrders()` · `openedOrders(String sort)`

```java
public OpenedOrdersData openedOrders()
public OpenedOrdersData openedOrders(String sort)
```

All currently open orders (market + pending). `sort` is a friendly alias mapped to `EnumOpenedOrderSortType` — `"open_asc"`, `"open_desc"`, `"ticket_asc"`, `"ticket_desc"` (or a raw enum name); `null` uses the default. The no-arg overload uses `SORT_BY_OPEN_TIME_ASC`.

```java
var data = service.openedOrders("open_desc");
for (var o : data.getOrderInfosList())
    System.out.printf(Locale.ROOT, "%d %s %.2f %+.2f%n", o.getTicket(), o.getSymbol(), o.getLots(), o.getProfit());
```

> **Underlying:** [`MT4Account.openedOrders`](../MT4Account/2.%20Orders_History/opened_orders.md) — field table & sort enum.

public OpenedOrdersTicketsData openedOrdersTickets()

System.out.println(service.openedOrdersTickets().getTicketsList());

## `ordersHistory()` · `ordersHistory(String sort, Instant since, Instant until, Integer page, Integer pageSize)`

```java
public OrdersHistoryData ordersHistory()
public OrdersHistoryData ordersHistory(String sort, Instant since, Instant until, Integer page, Integer pageSize)
```

Closed orders over a window. The service maps `sort → EnumOrderHistorySortType` (default `"close_desc"` / `HISTORY_SORT_BY_CLOSE_TIME_DESC`), `since/until → from/to`, and `page/pageSize → pageNumber/itemsPerPage`. Any boxed argument may be `null`.

```java
Instant end = Instant.now();
var hist = service.ordersHistory("close_desc", end.minus(30, ChronoUnit.DAYS), end, null, null);
System.out.printf("%d closed orders%n", hist.getTotalCount());
```

> **Underlying:** [`MT4Account.ordersHistory`](../MT4Account/2.%20Orders_History/orders_history.md) — sort enum values and paging.
