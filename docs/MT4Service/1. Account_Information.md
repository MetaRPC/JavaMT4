# MT4Service — Account Information

> Account state through the mid-level facade.

Account snapshot plus the performance/history family (statistics, equity curve, unrealized-P/L extrema). Each is a thin pass-through to the matching [`MT4Account`](../MT4Account/1.%20Account_Information/Account_Information.Overview.md) method; the stats methods take a friendly `since` (`Instant`) instead of the raw `from`.

---

## `accountSummary()`

```java
public AccountSummaryData accountSummary()
```

Returns the full account snapshot — balance, equity, margin, leverage, currency, trade mode, server time. Identical payload to the low-level call.

```java
var s = service.accountSummary();
double floating = s.getAccountEquity() - s.getAccountBalance();
System.out.printf(Locale.ROOT, "Balance %.2f %s | floating %+.2f%n",
        s.getAccountBalance(), s.getAccountCurrency(), floating);
```

> **Underlying:** [`MT4Account.accountSummary`](../MT4Account/1.%20Account_Information/account_summary.md) — full field table & enums.

---

## `tradeStats(Instant since)`

```java
public StatsData tradeStats(Instant since)
```

Aggregated statistics — profit factor, win/loss, drawdowns, per-market breakdown. `since` scopes the window (pass `null` for full history).

```java
var st = service.tradeStats(null);
System.out.printf(Locale.ROOT, "PF=%.2f trades=%d growth=%+.2f%%%n",
        st.getProfitFactor(), st.getTrades(), st.getGrowthPercent());
```

> **Underlying:** [`MT4Account.tradeStats`](../MT4Account/1.%20Account_Information/trade_stats.md).

## `tradeUnrealizedPl(Instant since)`

```java
public TradeUnrealizedPLData tradeUnrealizedPl(Instant since)
```

Per-open-order MFE/MAE excursions (`getExtremaList()`).

```java
System.out.println("extrema entries: " + service.tradeUnrealizedPl(null).getExtremaCount());
```

> **Underlying:** [`MT4Account.tradeUnrealizedPl`](../MT4Account/1.%20Account_Information/trade_unrealized_pl.md).

## `equityHistory(Instant since, Boolean excludeSameBars)`

```java
public EquityHistoryData equityHistory(Instant since, Boolean excludeSameBars)
```

The equity curve (`getPointsList()`). Pass `excludeSameBars = true` to shrink the payload.

```java
System.out.println("equity points: " + service.equityHistory(null, true).getPointsCount());
```

> **Underlying:** [`MT4Account.equityHistory`](../MT4Account/1.%20Account_Information/equity_history.md).

## `tradeStatsEquityHistory(Instant since, Boolean excludeSameBars)`

```java
public StatsWithChartsData tradeStatsEquityHistory(Instant since, Boolean excludeSameBars)
```

Stats + equity curve + trades in one call (`getStats()`, `getChartsList()`, `getTradesList()`, `getOpenTradesList()`).

```java
var r = service.tradeStatsEquityHistory(null, true);
System.out.printf("charts=%d trades=%d open=%d%n",
        r.getChartsCount(), r.getTradesCount(), r.getOpenTradesCount());
```

> **Underlying:** [`MT4Account.tradeStatsEquityHistory`](../MT4Account/1.%20Account_Information/trade_stats_equity_history.md).
