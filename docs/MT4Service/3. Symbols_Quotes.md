# MT4Service — Symbols & Quotes

> Symbols, quotes and bar history — with a **string timeframe** and an **auto-computed history window**.

Over [MT4Account](../MT4Account/3.%20Symbols_Quotes/Symbols_Quotes.Overview.md) the facade accepts a string `timeframe = "H1"` and derives a history window from `limit` when you don't pass dates. Everything else is a typed pass-through (the returned payloads are the same `…Data` messages — no list unpacking at this layer).

---

## `symbols()`

```java
public SymbolsData symbols()
```

The full symbol list. Pass-through — read `getSymbolNameInfosList()`.

```java
var syms = service.symbols().getSymbolNameInfosList();
System.out.println(syms.size() + " symbols");
```

> **Underlying:** [`MT4Account.symbols`](../MT4Account/3.%20Symbols_Quotes/symbols.md).

---

## `quote(String symbol)` · `quoteMany(List<String> symbols)`

```java
public QuoteData quote(String symbol)
public QuoteManyData quoteMany(List<String> symbols)
```

Pass-throughs. `quote` returns one `QuoteData` (`getBid()`/`getAsk()`/`getHigh()`/`getLow()`/`getDateTime()`); `quoteMany` returns `QuoteManyData` with `getQuotesList()`.

```java
var q = service.quote("EURUSD");
System.out.println(q.getBid() + " / " + q.getAsk());

for (var qq : service.quoteMany(List.of("EURUSD", "GBPUSD")).getQuotesList())
    System.out.println(qq.getSymbol() + " " + qq.getBid() + " " + qq.getAsk());
```

> **Underlying:** [`quote`](../MT4Account/3.%20Symbols_Quotes/quote.md) · [`quote_many`](../MT4Account/3.%20Symbols_Quotes/quote_many.md).

## `quoteHistory(String symbol, String timeframe, Instant since, Instant until, Integer limit)`

```java
public QuoteHistoryData quoteHistory(String symbol, String timeframe, Instant since, Instant until, Integer limit)
// also: quoteHistory(String symbol, ENUM_QUOTE_HISTORY_TIMEFRAME timeframe, Instant since, Instant until)
```

OHLC bars with a **string timeframe** (`"M1"`, `"M5"`, `"M15"`, `"M30"`, `"H1"`, `"H4"`, `"D1"`, `"W1"`, `"MN1"`; a raw enum name also works). If you don't pass `since`/`until`, the service computes the window as `timeframe × limit` ending now (`until` defaults to now, `limit` defaults to 100).

```java
// last ~100 H1 bars, no dates needed
var data = service.quoteHistory("EURUSD", "H1", null, null, 100);
var bars = data.getHistoricalQuotesList();
for (var b : bars.subList(Math.max(0, bars.size() - 3), bars.size()))
    System.out.printf(Locale.ROOT, "O=%.5f H=%.5f L=%.5f C=%.5f%n", b.getOpen(), b.getHigh(), b.getLow(), b.getClose());
```

> **Underlying:** [`MT4Account.quoteHistory`](../MT4Account/3.%20Symbols_Quotes/quote_history.md) (takes the `ENUM_QUOTE_HISTORY_TIMEFRAME` enum directly).

## `symbolParamsMany(String symbolName)`

```java
public SymbolParamsManyData symbolParamsMany(String symbolName)
```

Per-symbol trading parameters. `symbolName` for one symbol; `null` for all. Pass-through — read `getSymbolInfos(0)`.

```java
var info = service.symbolParamsMany("EURUSD").getSymbolInfos(0);
System.out.println(info.getDigits() + " " + info.getVolumeMin() + " " + info.getVolumeStep());
```

> **Underlying:** [`MT4Account.symbolParamsMany`](../MT4Account/3.%20Symbols_Quotes/symbol_params_many.md) — the full ~75-field spec and SP enums.

## `tickValueWithSize(List<String> symbols)`

```java
public TickValueWithSizeData tickValueWithSize(List<String> symbols)
```

Tick value / size / contract size for a list of symbols. Pass-through — read `getInfosList()`.

```java
for (var i : service.tickValueWithSize(List.of("EURUSD", "XAUUSD")).getInfosList())
    System.out.println(i.getSymbolName() + " " + i.getTradeTickValue());
```

> **Underlying:** [`MT4Account.tickValueWithSize`](../MT4Account/3.%20Symbols_Quotes/tick_value_with_size.md).

## `symbolSelect(String symbol, boolean select)`

```java
public SymbolSelectData symbolSelect(String symbol, boolean select)
```

Add a symbol to (or remove it from) Market Watch. Pass-through — read `getSuccess()`.

```java
System.out.println("selected: " + service.symbolSelect("XAUUSD", true).getSuccess());
```

> **Underlying:** [`MT4Account.symbolSelect`](../MT4Account/3.%20Symbols_Quotes/symbol_select.md).

## `serverTimezone()`

```java
public ServerTimezoneData serverTimezone()
```

Trade-server timezone / UTC offset. Pass-through.

```java
var tz = service.serverTimezone();
System.out.printf("%s: UTC offset %ds%n", tz.getServer(), tz.getUtcOffsetSeconds());
```

> **Underlying:** [`MT4Account.serverTimezone`](../MT4Account/3.%20Symbols_Quotes/server_timezone.md).
